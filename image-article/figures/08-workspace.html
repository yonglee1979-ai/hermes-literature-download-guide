第四步：
把“工作台”摆好

在电脑上建立 literature_demo 文件夹

本教程使用本机执行后端

hermes config set terminal.backend local
hermes config set terminal.cwd .

macOS / Linux / WSL2

mkdir -p ~/Documents/literature_demo
cd ~/Documents/literature_demo
hermes

Windows PowerShell

Set-Location "$HOME\Documents"
mkdir literature_demo
Set-Location literature_demo
hermes
上面每行单独执行。
已有同名文件夹就跳过创建。
进入文件夹后再启动我。
本机后端会操作电脑文件；指定文件夹是任务范围，不是权限隔离。
